Privacy Policy — Broken Vet Gaming Inventory
Last updated: 16 November 2026

This policy covers "Broken Vet Gaming Inventory", a private stock-keeping
application operated by Anthony Shewmake.

Who uses it
The application is personal software with a single user: its operator. It is
not published, sold, distributed, or made available to anyone else, and no
other person can sign in to it or use it.

Where it runs
It runs locally on the operator's own computer. It is not hosted on the public
internet and is reachable only from the operator's own home network.

What eBay data it accesses
Using read-only permissions, and only for the operator's own eBay seller
account, it reads that account's own listings and orders. It cannot and does
not read, display, or collect data belonging to any other eBay account. It
writes nothing back to eBay.

What it stores
Stock records created by the operator: item titles, platforms, condition,
purchase cost, internal SKU numbers, storage locations, and photographs taken
by the operator. From eBay it retains only values relating to the operator's
own activity: the operator's own listing identifiers and order identifiers,
the sale price, the fulfilment status, and the tracking number of the parcel
posted.

What it does not store
No personal data belonging to any other eBay user. No buyer names, postal
addresses, email addresses, telephone numbers, usernames, messages, or payment
details are written to disk at any point. Responses from eBay are held in
memory only for the duration of the request and are then discarded.

Sharing
Nothing is shared with, sold to, or transmitted to any third party. There is
no analytics, advertising, or tracking of any kind. Data stays on the
operator's own computer.

Retention and deletion
Records are kept for as long as the operator finds them useful and can be
deleted by the operator at any time. Because the application holds no personal
data belonging to any other person, there is no third-party data to delete on
request.
